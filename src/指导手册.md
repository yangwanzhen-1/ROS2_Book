# 指导手册

本手册用于说明如何维护和扩展这本 ROS 2 笔记。

## 项目结构

```text
ROS2_Book/
├── .nvmrc           # Node.js 版本
├── book.json        # GitBook 配置
├── src/             # Markdown 源文件
│   ├── SUMMARY.md   # 书籍目录
│   └── *.md         # 各章节内容
└── _book/           # 构建生成的网站文件
```

平时只需要编辑 `src` 目录。`_book` 目录由 GitBook 自动生成，不需要手动修改。

## 添加新章节

首先在 `src` 目录中创建一个 Markdown 文件，例如：

```text
src/ros2_node.md
```

然后编写章节内容：

````markdown
# ROS 2 节点

这里记录 ROS 2 节点相关知识。

```cpp
auto node = std::make_shared<rclcpp::Node>("demo_node");
```
````

最后在 `src/SUMMARY.md` 中添加目录项：

```markdown
- [ROS 2 节点](./ros2_node.md)
```

只有添加到 `SUMMARY.md` 中的文件，才会显示在书籍目录里。

## 添加多级目录

可以使用缩进组织章节：

```markdown
- [ROS 2 基础](./basics.md)
  - [节点](./basics/node.md)
  - [话题](./basics/topic.md)
  - [服务](./basics/service.md)
```

对应文件结构为：

```text
src/
├── basics.md
└── basics/
    ├── node.md
    ├── topic.md
    └── service.md
```

## 本地预览

在 `ROS2_Book` 目录中执行：

```bash
nvm use
gitbook serve
```

浏览器访问 `http://localhost:4000`。修改 Markdown 文件后，页面通常会自动刷新。

## 构建书籍

执行：

```bash
nvm use
gitbook build
```

生成的网站文件保存在 `_book` 目录中。

构建结果也支持直接打开 `_book/index.html`。项目中的 `file-navigation` 本地插件会在
`file://` 模式下使用普通页面跳转，避免浏览器拦截 GitBook 的 AJAX 章节加载。

插入代码块时，可以标注代码语言以启用语法高亮：

````markdown
```cpp
#include <iostream>

int main()
{
  std::cout << "Hello, ROS 2!" << std::endl;
  return 0;
}
```
````

网页中的多行代码块右上角带有“复制”按钮。点击后会复制代码内容，并短暂显示
“已复制”状态。



```c++
#include <memory>

#include "nav2_lifecycle_manager/lifecycle_manager.hpp"
#include "rclcpp/rclcpp.hpp"

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<nav2_lifecycle_manager::LifecycleManager>();
  rclcpp::spin(node);
  rclcpp::shutdown();

  return 0;
}

```
